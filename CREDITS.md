# CREDITS

## FileGrove

FileGrove is a clean-room reimplementation of a desktop file-organizer
application. It was inspired by **File Arbor** by **Furkan Bagci**
(https://github.com/furkanbagci34/file-arbor-releases), but contains no
code from the original product. The implementation is based solely on
observed behavior of the original binary release, documented in
`docs/SPEC.md`.

We acknowledge the original author for the product idea, the thoughtful
UX design, and the choice to release under an open-source license (MIT).
Without that foundation, FileGrove would not exist.
