# Relajación del gate de escaneo — 2026-11-22 (T6)

## Qué cambió

`src-tauri/src/ipc/files.rs`, `organize_inner_with_gate`:

- Los early-return que abortaban todo el organize con `SCAN_LIMIT_REACHED`
  (cap de 100k archivos) u `SCAN_INCOMPLETE` (errores de lectura) fueron
  reemplazados por `tracing::warn!` que no detienen la corrida: ahora se
  organiza el subconjunto legible.
- El resultado del `execute_plan` ahora incluye `scanTruncated` y
  `scanUnreadable` en `data`, listos para un aviso de UI futuro.
- Seguridad del cambio: cada archivo se valida individualmente
  (`validate_source_file`) y se revalida justo antes de su move
  (`revalidate_immediately_before_action`); los ilegibles no entran al plan y
  nunca se mueven a ciegas. `emit_organize_error` se conserva para el branch de
  scan fallido.
